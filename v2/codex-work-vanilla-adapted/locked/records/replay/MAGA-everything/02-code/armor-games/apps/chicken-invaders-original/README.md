# Cluck Horizon · Special Delivery

An original courier-versus-poultry arcade shooter on `@maga/shmup-core`, shared with Starfall Flock. The Breakfast Belt and Royal Roost Express each contain ten named formations and one commander: **22 encounters**, the full two-sector concept scope. Six formation behaviors and three distinct enemies feed a kitchen-tech weapon progression: Soup Laser → Spatula Spread → Whisk Barrage. Mother Goose and Rooster Regent have different volleys, burst counts, motion and faster second phases.

The courier, Flockbird, Glider, Bruiser and commanders use original authored SVGs, with teal/orange palettes, ration crates, courier jokes and two original synth beds. Each sector has its own orbital backdrop and music. Rations refill missiles. Every 5,000 points adds one capped life; commander clears repair one life and refill one missile. Wave checkpoints restore earned equipment/score/lives at the start of the saved wave. Best score, unlocks, music/motion preferences and touch layout persist independently under `maga:chicken-invaders-original:`. Master volume and mute use the arcade-wide audio preference.

Desktop controls, explicit twin-thumb / one-thumb touch modes, reduced motion, volume/music settings, Save & Hangar and offline verification commands are shared with [Starfall Flock](../chicken-invaders/README.md). Portrait has a readable status and large native launch/continue controls. Losing focus pauses and releases held input.

Run `npm run dev:cluck` from the monorepo directory (port 5177). Build with `npm run build -w @maga/chicken-invaders-original -- --base ./`. The app boots the `cluck` content pack; there is no separate game engine or copied simulation. All graphics and music are original, with no extracted commercial assets.

`proofs/ship/` contains current receipts and screenshots. Browser campaign proof uses read-only observation and browser KeyboardEvents (`isTrusted=false`) through production input handlers, with controlled 20 Hz animation callbacks and the unchanged 120 Hz production physics. Native menu/keyboard checks and native CDP touch movement smoke are separate; touch wave checks use browser PointerEvents (`isTrusted=false`) through the production touch zones. No game state is injected. `proofs/baseline/` holds the original checkpoint play; `proofs/balance/` preserves intermediate normal wall-clock full-campaign play. Physical mobile devices and Safari are not claimed.
